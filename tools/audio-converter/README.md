# ツクール音声変換帳

HTML / CSS / Vanilla JavaScriptの静的ツールです。ビルド・npm・バックエンドは不要です。

## 開く

リポジトリ直下で `python3 -m http.server 8000` を実行し、
`http://localhost:8000/tools/audio-converter/` を開いてください。
ES ModulesとWeb Workerを使うため、HTMLの直接ダブルクリック（file://）では変換できません。
8000番が使用中なら、8001など別のポートを指定してください。

## できること

- ドラッグ＆ドロップまたは複数ファイル選択。20件、各50MB、合計200MBまで。
- 01の選択欄で「○件選択済み」を表示。追加・削除・全解除と連動し、02の一覧へ移動できます。
- 先頭シグネチャの簡易判定と、変換時のFFprobeによる音声ストリームの検証。
- Ogg Vorbis（品質4）とAAC-LC/M4A（160kbps）への一括変換。
- 44.1kHzに統一。モノラル・ステレオを維持し、3ch以上はステレオへ変換。
- オプションの音量調整（loudnorm）と前後無音の短縮。初期値はどちらも無効。
- 保存名の編集、半角英数字への整形、同名の連番付与。
- M4A/OGGの試聴切り替え、各形式の個別保存。
- 完了した音源のZIP保存。ZIP直下に2形式を並べ、audio/seなどのフォルダは作らない。
- 途中の変換中断と残りの再開、不正な音声のエラー表示。

音声はサーバーへ送信しません。入力は1件ずつエンジンへ渡し、仮想ファイルは毎回削除します。
ページを閉じると入力と出力を解放します。元ファイルは書き換えません。
対応形式でも壊れた音声、暗号化音声、端末のメモリを超える音声は変換できない場合があります。
ループ用メタデータの保持・設定には対応していません。

画面は「短い使い方 → 01の選択欄 → 仕上げの設定 → 02の一覧」の順です。
保存先やフォーマットの詳しい説明は、下部の「小さな補足」にまとめています。

## GitHub Pages

ディレクトリ全体を公開してください。`vendor/ffmpeg/` の4つの実行ファイル、とくに約31MBの
`ffmpeg-core.wasm` を省略しないでください。これは100MB未満の通常ファイルで、Git LFSは不要です。
単一スレッドのエンジンなのでCOOP/COEPヘッダーは不要です。
すべてのアプリ内パスは相対パスまたはその相対パスから組み立てており、リポジトリ名付きURLでも動きます。

変換エンジンは「変換」の操作時だけ読み込み、トップページにはロードしません。
Google Fontsは見出し用です。読み込めなくてもシステムフォントへフォールバックします。

## 編集箇所

- `index.html`：説明、案内、画面構成。
- `style.css`：このツールだけの見た目。共通色はルートの`style.css`を継承。
- `app.js`：一覧・変換キュー・保存・中断。
- `audio-utils.js`：件数制限、保存名、形式の簡易判定、音声フィルター。
- `engine.js`：同梱ffmpeg.wasmの読み込みと解析。
- `archive.js`：追加ライブラリを使わないSTORE形式のZIP生成。
- `vendor/THIRD_PARTY.md`：ライブラリの出典とライセンス。

## 検証

開発用にNode.jsがある場合は `node --test tools/audio-converter/tests/core.test.mjs` で
保存名、シグネチャ判定、フィルター設定、ZIP構造・CRCの検証を実行できます。
サイトの利用・公開にNode.jsは不要です。

ブラウザでは、モノラル/ステレオ、拡張子を変更したWAV、不正な音声、空ファイル、
試聴切り替え、個別保存・ZIP、中断・再開、スマートフォン幅を確認してください。

実装時には上記に加え、実際のMP3/FLAC/OGG/M4A入力、75秒の音声に対する両フィルターの併用、
OGG/M4Aの実再生、リポジトリ名付きURL、390px幅での表示をブラウザで確認しています。
保存後のファイルもFFprobeでVorbis / AAC-LC、44.1kHz、元のチャンネル数を検証しました。
