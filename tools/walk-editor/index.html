はじめての使い方

最初に表示されるロボットでも、そのまま試せます。

  1. PNGをひらく

    自分の歩行グラを読み込みます。単体は3列×4行、8キャラシートは12列×8行。合わないときは「読み込む配置」を選んでください。

  2. キャラ・コマを選ぶ

    8キャラシートなら「編集するキャラ」を選択。「12コマを並べる」の一覧から、編集したいコマを押します。

  3. 描いて、歩かせる

    鉛筆や消しゴムで編集し、「歩いてみる」で動きを確認。失敗したら「戻す」で取り消せます。

  4. PNGで保存する

    ページ下部の「PNGで保存」で書き出します。選択キャラだけ／シート全体を選べます。単体の保存名には $ が付きます。

標準の1コマは48×48px。倍率は表示だけを拡大し、保存サイズは変えません。

編集は自動保存されません。ページを閉じる・更新する前にPNGを保存してください。

PNGをこのページにドロップしても読み込めます。MV / MZ向け・標準48px。最大8MB。

画像の形式・保存について

通常歩行の3列×4行、または8キャラの12列×8行のPNGに対応。1コマは縦横それぞれ8〜128pxです。顔グラ・ダメージグラの編集やAI自動生成は対象外です。読み込んだファイル自体は変更せず、等倍の透過PNGを新しく保存します。単体キャラには先頭に $ を付けます。

リサイズ・補間・減色はしません。ブラウザで画像を読み直すため、PNGの圧縮方式・付加情報・完全透明な部分の見えない色情報は維持されない場合があります。

編集データと素材の扱い

編集内容はこのタブ内にだけ保持します。閉じる・更新する前にPNGを保存してください。Undoは最大100操作（変更量によってはそれ以下）です。元画像と比較するための原本は保持します。画像はサーバーに送信しません。

ご自身が編集・利用できる素材を読み込んでください。ツールの利用で素材の権利や利用条件は変わりません。同梱のロボットはこのツール用のオリジナルサンプルです。ゲームへの利用・改変可、クレジット不要です。

細かな作業はPCがおすすめです。スマートフォンではタッチで描画でき、編集エリア内は横スクロールできます。
