# ツクール歩行グラ編集帳

ビルド・外部ライブラリ・バックエンド不要の歩行グラPNGエディター。HTML / CSS / Vanilla JavaScriptだけで動作し、画像は端末内で処理します。

## 対応と機能

- 通常歩行の単体3×4、8キャラシート12×8。1コマ8〜128px、PNG最大8MB。
- 先頭が `$` のファイルを単体、それ以外を8キャラと自動判定。読み込み前に配置を明示することも可能。
- 鉛筆・消しゴム・スポイト・4連結塗りつぶし・RGBAと不透明度・キャラごとのパレット。
- 原本・編集中・差分・比較。最大100操作のUndo/Redo（変更量によるメモリ上限あり）。
- コマ選択、対象を限定した色置換、変更のみ／全コマのコピー、整数オフセット。
- 4方向の歩行プレビュー、再生・停止・速度設定。動きを減らす設定時は停止で開始。
- 透過PNGを等倍で保存。選択キャラは3×4で先頭に `$`、全シートは元の寸法。
- タッチ・キーボード操作、素材の入れ替え／終了時の未保存警告。

顔グラ・ダメージグラ・AI生成機能は含みません。個人用の `tools/sprite-tool/` と独立しており、スキル・素材・履歴・ローカルファイルのパスを読み込みません。

## 保存の注意

編集内容はこのタブ内だけに保持します。元ファイルは上書きせず、PNGをダウンロードします。PNGはブラウザで再エンコードするため、圧縮・メタデータ・完全透明なピクセルの見えないRGBは変わる場合があります。読み込み後のRGBAを基準に、対象外キャラのドットを保持します。

自分が利用・編集できる素材を使ってください。素材の権利・利用条件を変更するツールではありません。オリジナルロボットのサンプル（`sample.js`）はゲームへの利用・改変可、クレジット不要です。

## 確認・公開

リポジトリ直下からHTTPサーバーを起動し、`http://localhost:8000/tools/walk-editor/` を開きます。ES Modulesのため `file://` での直接起動ではなくHTTPを使ってください。GitHub Pagesのプロジェクト配下でも動く相対パスです。

```sh
python3 -m http.server 8000
node --test tools/walk-editor/tests/pixels.test.mjs
```

`pixels.js` が純粋な編集処理、`app.js` がブラウザ操作、`sample.js` が公開専用サンプルです。ローカル版のPythonサーバーやAI制作スキルは公開不要です。
